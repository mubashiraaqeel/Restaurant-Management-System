# 🍽️ Restaurant Management System

A **Python-based Restaurant Management System** developed using **Object-Oriented Programming (OOP)** and **JSON** for data storage. This console application helps manage restaurant operations such as menu items, customers, employees, tables, orders, invoices, payments, reports, and statistics.

---

## 📌 Features

### 🍕 Menu Management
- Add Menu Item
- View Menu
- Search Menu Item
- Update Menu Item
- Delete Menu Item

### 👤 Customer Management
- Add Customer
- View Customers
- Search Customer
- Update Customer
- Delete Customer

### 👨‍🍳 Employee Management
- Add Employee
- View Employees
- Search Employee
- Update Employee
- Delete Employee

### 🪑 Table Management
- Add Table
- View Tables
- Search Table
- Update Table
- Delete Table
- Reserve Table

### 📝 Order Management
- Place Order
- View Orders
- Search Order
- Update Order
- Complete Order
- Cancel Order

### 🧾 Billing & Invoice Management
- Generate Invoice
- View Invoices
- Apply Discount

### 💳 Payment Management
- Make Payment
- Search Payment
- Payment History

### 📊 Reports
- Daily Sales Report
- Monthly Sales Report
- Customer Report
- Employee Report
- Payment Report

### 📈 Statistics
- Total Customers
- Total Employees
- Total Menu Items
- Available & Reserved Tables
- Available & Unavailable Menu Items
- Pending, Completed & Cancelled Orders
- Total Invoices
- Total Payments
- Total Sales

## 💾 Data Storage

All application data is stored in a JSON file.

The system stores:

- Menu Items
- Customers
- Employees
- Tables
- Orders
- Invoices
- Payments

Data is automatically saved after every successful operation.

## ▶️ How to Run

Clone the repository

```bash
git clone https://github.com/mubashiraaqeel/Restaurant-Management-System.git
```

Go to the project folder

```bash
cd Restaurant-Management-System
```

Run the project

```bash
python main.py
```
